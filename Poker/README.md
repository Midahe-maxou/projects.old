## Poker python

Site et jeu de poker en python pour un projet en NSI.<br>
Le site web, créé avec Flask permet de s'inscire et de télécharger le jeu. Les données clients sont stockés en clair dans un fichier texte.<br>
TKinter à été utilisé pour faire l'interface graphique du jeu de poker (essaie.py).<br>
Nous avions utilisé de la programmation fonctionnelle, donc il n'y a pas de classe, mais il y a beaucoup de définition de fonction à l'intérieur de fonctions plus générale.
Par exemple la fonction `reconnaitre_combinaisons(cartes, main)` possède une fonction pour chaque combinaison (pair, double pair, suite...).<br>
