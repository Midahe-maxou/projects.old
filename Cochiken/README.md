## Cochiken

Site de vente de cosmétique de poulet de compagnie. Réalisé en PHP pour un projet de NSI.

### Fonctionnalités

- Gestion de compte client avec une base SQL (Vulnérable par injection SQL).
- Boutique non fonctionnelle proposant divers accessoire pour poulet.

Pour l'oral de présentation du projet, le site était hébergé sur mon ordinateur personnel, accessible via IP (sans nom de domaine).<br>
C'était une bonne idée si le pare-feu du lycée autorisait les connections avec seulement une IP, ce qu'il ne fait pas ._.
